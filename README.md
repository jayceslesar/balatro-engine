# Balatro Engine
Toy project to create a [Balatro](https://www.playbalatro.com/) backend

## Development
#### This project uses [PDM](https://github.com/pdm-project/pdm)

1. Clone the repository
2. `cd` into the cloned repository
3. `pdm sync -G:all`


### Linting
Linting can be run with `pdm run lint`. This uses the default [ruff](https://github.com/astral-sh/ruff) configuration for formatting and linting and mypy for type checking.
